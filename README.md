# CMPE 125 labs (SJSU)

Verilog labs and homework from CMPE 125 (digital logic), Fall 2026. Built in Vivado 2025.2 and run on a Basys3 FPGA board (Artix-7). All work is solo.

| Folder | What it is |
|---|---|
| [lab2-full-adder](lab2-full-adder) | 1-bit full adder, all 8 inputs simulated |
| [lab3-hex-decoder](lab3-hex-decoder) | 4-bit hex to seven-segment decoder |
| [lab4-5-cla-adder](lab4-5-cla-adder) | 4-bit carry-lookahead adder with directed and vector-file tests |
| [hw-sequential-logic-fsm](hw-sequential-logic-fsm) | Flip-flops, a Gray code counter and a Mealy state machine |

Lab 1 (a blinking LED and an XOR gate from the Digilent tutorial) is not included.
